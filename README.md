# うごくノート2

**うごくノート2**は、ブラウザだけで動くパラパラまんが・フレームアニメーション制作ツールです。
絵を描き、コマを増やし、音を付け、再生し、GIF・動画・連番画像・ppm(DSi)・kwz(3DS)形式へ書き出せます。

作品データは基本的にブラウザ内で処理され、描画のために外部サーバーへアップロードする必要はありません。
PCのマウス・ペンタブだけでなく、スマートフォンやタブレットのタッチ操作にも対応しています。
最大8枚の描画レイヤー、選択変形、13種類のブラシ、手描きゆらぎ、端末内のうごきアシスト、エフェクト、トランジション、BGM・SE、動画からのコマ抽出、PPM/KWZ入出力などを備えています。

## できること

### 描く

* ペン、消しゴム、塗りつぶし、スポイト、ドット描画
* 直線、四角、円、星、ハートなどの図形
* 文字入力、縦書き、袋文字、フォント取り込み
* 13種類のブラシ

  * ペン
  * マーカー
  * えんぴつ
  * ふで
  * エアブラシ
  * クレヨン
  * つけペン
  * てんてん
  * すいさい
  * ネオン
  * チョーク
  * しぶき
  * リボン
* 手ぶれ補正、筆圧による太さ、不透明度、フチ取り
* 左右対称・上下対称描画
* ドット、格子、市松、横線などのパターン塗り
* 自作色の登録
* 選択範囲や画像からマイマークを作り、スタンプとして再利用

描画を置き換える生成サービスではなく、描いた絵を残したまま動かしやすくする編集支援を備えています。

### 動かす

* ノーマルは最大9,999コマ、うごメモ・うごメモ3Dは最大999コマ
* 0.5 / 1 / 2 / 4 / 6 / 12 / 20 / 30 fps
* コマ追加、複製、削除、並べ替え
* 各コマを1〜8コマ分まで保持するホールド設定
* A-B区間ループ
* 範囲の逆順化、複製、往復アニメ化
* オニオンスキン表示（前後最大3コマ）
* フレームごとのサムネイルタイムライン
* ループ再生、コマ送り、先頭ジャンプ

### 手描きゆらぎとうごきアシスト

メニューの **つくる → うごきアシスト** から、描いた線や塗りを手描きらしく揺らせます。ノーマルモードでは元の画素を変更せず、表示時だけ決定論的な揺らぎを合成するため、設定だけならコマ数は増えません。うごメモ・うごメモ3Dモードでは再生時だけの設定を持たせず、選んだ動きを必ず編集可能な実コマへ変換します。

* 線と塗りを一緒にウネウネさせる手描きゆらぎ
* 揺れの強さ、細かさ、速さ、位相数、揺れ方の変更
* 呼吸、ゆらゆら、ふわふわ、ぴょこぴょこ、手持ちカメラ
* 絵の占有範囲、重心、輪郭密度から動きと支点を端末内で提案
* 現在の絵を編集可能なループ用コマへ変換
* 現在と次のコマの位置差を推定して中割りを追加

ノーマルモードで付けた設定だけの動きは、再生、GIF、PNG連番、動画、PPM、KWZへ反映されます。静止PNGは現在位置の見た目を1枚だけ保存します。ノーマル作品をPPM/KWZへ書き出す場合は、形式の色とレイヤー制限へ量子化した上で、表示時の動きとホールドを実コマへ展開します。

分析と中割りはブラウザ内で完結し、画像を外部へ送信したり、モデルファイルをダウンロードしたりしません。大きな処理は短い時間枠へ分割し、設定プレビューは最大20fpsに抑えています。

スマホの再生・コマ操作バーは、前後移動、再生、現在位置、削除、追加、速度、コマ操作を画面内へ固定し、横方向へスクロールしません。複製、ループ、ホールド、速度、コマ一覧の開閉などはコマ操作メニューから選べます。横向きではサムネイルのコマ一覧を閉じ、縦向きへ戻したときに直前の開閉状態を復元します。

### レイヤーを使う

ノーマルモードでは、写真レイヤーに加えて描画レイヤーを **A〜Hの最大8枚** まで使用できます。初期状態はA / B / Cの3枚で、必要なときだけ追加レイヤーを増やせます。

* 表示・非表示
* 並べ替え
* 不透明度調整
* 下のレイヤーと結合
* 別レイヤーへのコピー
* レイヤー単位の消去
* 追加レイヤーの作成と削除

レイヤー追加と追加レイヤーの削除はノーマルモード専用です。うごメモモードはA / B、うごメモ3DモードはA / B / Cに固定されます。ノーマルで作ったD〜Hは制限モードへ切り替えても破棄せず非表示で保持し、ノーマルへ戻すと再び編集できます。

PPM書き出し時は形式の制約に合わせて2レイヤーへ集約され、KWZ書き出し時は3レイヤー・対応色へ量子化されます。

### 選んで変形する

* 四角選択、なげなわ選択
* コピー、切り取り、貼り付け、複製、削除
* 移動、回転、拡大・縮小
* 左右反転、上下反転、90度回転
* 矢印キーによる1px移動、Shift併用で10px移動
* レイヤー単体または全レイヤーの一括変形

### エフェクトをかける

選択範囲またはレイヤー全体へ、次のエフェクトを適用できます。

* ぼかし
* モザイク
* 発光
* 色ずれ
* ノイズ
* フチ抽出
* 波形変形

適用前にプレビューできるため、思っていた芸術とただの事故を見分けやすくなっています。

### トランジションを作る

隣り合う2コマの間へ中間フレームを自動生成できます。

* フェード
* 上下左右へのスライド
* ズームイン
* ズームアウト
* ワイプ

生成枚数を指定でき、結果は通常のコマとして挿入されます。

### 音を付ける

* BGMスロット × 2
* SEスロット × 4
* 音声ファイルの読み込み
* マイク録音
* 再生しながら行うアテレコ録音
* BGM・SE音量調整
* コマごとのSE割り当て
* コイン、ジャンプ、ヒット、チャイムなどのSEプリセット

音声はプロジェクトと一緒に保存できます。録音にはブラウザのマイク権限が必要です。

PPM/KWZへ書き出す音声は、ステレオや多チャンネルの全チャンネルをモノラルへまとめ、BGMの再生速度と音量を反映してから、形式ごとの標本化周波数へアンチエイリアス付きで変換します。2本のBGMを重ねた場合もピークを確認してから量子化するため、片チャンネルの欠落、折り返し雑音、単純なクリッピングを抑えます。ただし、PPMは8180Hz、KWZは16364HzのモノラルADPCMという形式上の上限を超える音質にはなりません。

### 画像からうごメモを作る

メニューの **つくる → 画像からうごメモ** から、1枚の画像をPPMまたはKWZ向けの編集可能なノートへ変換できます。写真レイヤーへ置く通常の「写真」取り込みとは別の機能です。

* 配置は「画面いっぱい」と「画像全体」から選択
* 1・4・8・16コマの時間ディザを選択
* 紙色の自動選択または固定
* 明暗と彩度を変換前に調整
* 実際に生成される制限済みコマを30fpsでプレビュー
* ノートだけを作るか、作成後すぐ書き出し画面へ進むかを選択

16コマでは、同じ画像を少しずつ異なるドット配置へ分解します。再生時に時間方向でも混色されるため、少ない実機色のまま静止画より細かな階調を表現できます。生成されたコマは通常のコマと同じように加筆、消去、並べ替え、音付けができます。

PPM変換は256×192、紙1色、固定した2つのインク、2描画レイヤーに収めます。画像全体を見て白紙または黒紙と2インクを一度だけ選ぶため、コマごとの色の揺れを避けます。

KWZ変換は中央310×230の編集領域を使い、白・黒・赤・黄・緑・青の6色すべてを候補にします。黒/白、赤/緑、黄/青を3レイヤーへ2色ずつ割り当てるため、赤・緑・青の三原色を含む色域を形式の上限まで利用できます。紙に選ばれた色は透明部分として扱います。

形式の色、透明度、レイヤー数、重なりの条件を保っているコマは、書き出し時に再減色せずPPM/KWZの面データへ直接変換します。加筆によって条件を外れたコマだけ、通常の安全な減色処理へ自動的に切り替わります。

## モード

| モード | キャンバス | 描画レイヤー | 特徴 |
| --- | ---: | ---: | --- |
| ノーマル | 初期値 512×288 | 最大8枚 | 色・ブラシ・比率を自由に使う拡張モード |
| うごメモ | 256×192 | 2枚固定 | DSi風の実寸キャンバスとPPM向けパレット |
| うごメモ3D | 310×230 | 3枚固定 | 3DSの描画領域とKWZ向け6色パレット |

モードを切り替えると、キャンバスサイズや色の扱いが変わります。
通常の描画と再生はどのモードでも利用できます。うごきアシストは全モードで開けますが、コマを増やさない再生時設定はノーマルモードだけです。うごメモ・うごメモ3Dモードでは適用時に必ず実コマへ変換します。追加レイヤーもノーマルモードに限定し、PPM/KWZ書き出し時には各形式へ合わせて色数・レイヤー構造を変換します。
KWZ内部のフレームは320×240ですが、通常の描画領域は中央の310×230です。読み込み時は周囲5ピクセルを除き、書き出し時は周囲5ピクセルを加えます。

ノーマルモードでは次の画面比率を選択できます。

* 4:3
* 16:9
* 1:1
* 3:4
* 9:16

低画質・中画質・HD・DSi実寸・3DS実寸の解像度プリセットも用意されています。

## 読み込めるもの

| 種類       | 用途                 |
| -------- | ------------------ |
| `.ugn2`  | うごくノート2の編集用プロジェクト  |
| `.kwz`   | うごメモ3D形式の作品        |
| `.ppm`   | DSi版うごメモ形式の作品      |
| 画像       | 写真レイヤーや素材として取り込み   |
| 動画       | 指定fpsで切り出し、複数コマへ変換 |
| PNG連番ZIP | 連番画像をフレームとして一括取り込み |
| 音声       | BGMまたはSEとして取り込み    |
| フォント     | 文字ツールでセッション中に使用    |

KWZ/PPMは入力値を検証し、読み取れる範囲を通常の編集状態へ変換します。破損の程度によっては読み込めない場合があります。

`.kwz`、`.ppm`、`.ugn2`などの独自拡張子は、OSのファイル選択画面で種類を固定すると選択不能になる環境があるため、選択画面では種類を絞り込みません。選択後にデコーダーが拡張子と内容を検証し、対応形式だけを読み込みます。画像、動画、音声は従来どおり種類を絞り込みます。

## 書き出せるもの

| 形式       | 内容                          |
| -------- | --------------------------- |
| PNG      | 現在のコマを1枚の画像として保存            |
| PNG連番ZIP | 全コマまたはA-B区間を連番PNGとして保存      |
| GIF      | ホールド時間を反映したアニメーションGIF       |
| MP4      | 対応ブラウザで動画として書き出し            |
| WebM     | MediaRecorder対応環境で動画として書き出し |
| KWZ      | うごメモ3D形式                    |
| PPM      | DSi版うごメモ形式                  |
| `.ugn2`  | 後から再編集できるプロジェクト形式           |

画像・動画は1倍、2倍、3倍の書き出し倍率を選択できます。
PNGとPNG連番ZIPは背景透過に対応し、GIFと連番ZIPはA-B区間だけを書き出すこともできます。再生時だけの手描きゆらぎや動きは、アニメーション形式では出力時刻ごとの画面へ展開されます。

MP4はブラウザのWebCodecs・H.264・AAC対応状況に依存します。MP4が未対応の場合はWebMをご利用ください。

### PPM / KWZの署名

PPMとKWZの書き出しでは、各形式に合わせたRSA署名をファイル末尾の所定位置へ付加します。
なお、本プロジェクトは非公式ツールです。署名が存在することと、任天堂公式ソフトで制作されたことは同義ではありません。読み込み先や検証環境によって互換性・判定結果が異なる場合があります。

### 作品情報とうごメモメタデータ

KWZ/PPMから読み込んだ作品情報を保持し、書き出し前に編集できます。

* 原作者・親作者・現在の編集者という3世代の作者名
* 各世代の作者ID
* 原作品・親作品・現在作品のファイル名履歴
* 作成日時、更新日時、編集回数
* ロック属性、コメント属性、生のフラグ類
* 作者IDからのリージョン判定
* 現在の編集者を親世代へ繰り下げる世代更新
* 形式ごとの命名規則に沿ったファイル名生成

作品を開いて絵だけ取り出し、作者情報を全部記憶喪失にする設計ではありません。
読めたメタデータは`.ugn2`にも保存され、再度KWZ/PPMへ書き出す際に引き継がれます。

## 保存とプライバシー

### 自動保存

編集内容はIndexedDBへ自動保存されます。通常は変更後およそ2.5秒で保存処理が走り、次回起動時に続きから再開できます。

### 保存スロット

ブラウザ内に8個の保存スロットがあり、作品名・サムネイル付きで複数プロジェクトを保管できます。
ブラウザのデータ削除機能を使用すると保存データも削除されるため、重要作品は`.ugn2`としてファイルにも保存してください。

### 通信

描画、保存、変換は基本的に端末内で行われます。
作品を編集するために専用サーバーへアップロードする仕組みはありません。
書き出したファイルは、対応端末ではWeb Share APIからSNSや他アプリへ共有できます。

## PWA・オフライン動作

HTTPSまたはlocalhostで配信するとService Workerが有効になり、PWAとしてインストールできます。
初回読み込み後は主要ファイルがキャッシュされ、ネットワークにつながらない環境でも起動しやすくなります。

`file://`で`index.html`を直接開いた場合も、多くの描画・読み込み・書き出し機能は動作します。ただし、次の機能は制限されることがあります。

* Service Worker
* PWAインストール
* マイク録音
* 共有API
* 一部の動画コーデック

本格的に使う場合は、ローカルサーバーまたはHTTPS配信を推奨します。

## 動かし方

### 必要なもの

* Node.js
* npm
* ES2020以降に対応した新しめのブラウザ

### インストールとビルド

```bash
npm install
npm run build
```

`src/main.ts`から`dist/app.js`、`src/worker.ts`から`dist/worker.js`が生成されます。

### ローカルサーバーで起動

Pythonが入っている場合は、プロジェクトのルートで次のコマンドを実行できます。

```bash
python -m http.server 8080
```

その後、ブラウザで次を開きます。

```text
http://localhost:8080/
```

配布ZIPには`dist/`が含まれているため、ソースを変更しない限り再ビルドせず、そのまま静的サーバーで配信できます。

## npmスクリプト

| コマンド                | 内容                          |
| ------------------- | --------------------------- |
| `npm run build`     | 通常ビルド                       |
| `npm run build:min` | JavaScriptを圧縮してビルド          |
| `npm run watch`     | ソース変更を監視し、アプリとWorkerを自動再ビルド |
| `npm run typecheck` | TypeScriptの型チェックのみ実行        |
| `npm run check`     | 型チェック後に圧縮済み本番ビルドを実行    |

公開用には`build:min`、開発中は`watch`を使用します。
`watch`中に画面へ反映されない場合は、Service Workerとブラウザキャッシュを更新してください。

## 基本的な使い方

1. メニューから「新規」を選ぶ
2. モード、比率、画質、紙の色を決める
3. ペンや図形で1コマ目を描く
4. 「コマ追加」または「複製」で次のコマを作る
5. オニオンスキンを見ながら少しずつ動かす
6. ノーマルモードで手描きの揺れだけが必要な場合は「うごきアシスト」で設定だけの動きを付ける
7. うごメモ系モードでは動きを実コマへ変換し、必要なら次のコマとの中割りも作る
8. 再生して動きを確認する
9. 必要に応じてBGMやSEを設定する
10. 書き出しハブからGIF、動画、PNG、KWZ、PPMなどを選ぶ

## 技術構成

中心はTypeScriptとCanvas APIです。
高頻度で更新されるキャンバス、タイムライン、ペン入力は素のTypeScriptで制御し、フォーム的な一部パネルにだけPreactを使用しています。

### 実行時にバンドルされる主な依存

* `perfect-freehand` — 描線の平滑化
* `mediabunny` — MP4の多重化・メディア処理
* `preact` — レイヤー・色パネルなど一部UI

### 開発用

* `TypeScript`
* `esbuild`

高頻度で更新される描画経路はCanvasへ直接反映し、フォーム的なパネルだけをPreactで構築しています。状態変更はコマンドへ集約し、必要な表示領域だけを更新します。

## ブラウザと端末について

最新に近いChrome、Edge、Firefox、Safari系ブラウザを想定しています。

* マウス、ペン、タッチ入力に対応
* レスポンシブUI
* ダークテーマ
* 日本語・英語切り替え
* PWAインストール
* Web Workerによる書き出し処理

端末のメモリが少ない場合、大きなキャンバス、多数のコマ、複数音声、高倍率書き出しを同時に使うと重くなることがあります。ノーマルは9,999コマまで扱えますが、実用的な枚数はキャンバス解像度と端末メモリに左右されます。
PCでは最大40段、モバイルでは最大20段のUndo履歴を基本とし、履歴全体にはメモリ上限があります。手描きゆらぎの合成画像も端末別の上限付きLRUキャッシュで管理し、同じ画面を毎回展開し直さないようにしています。

端末の空きメモリが少ない場合は、解像度やフレーム数を抑えてください。

## 注意点

* PPM/KWZは色数が少ないため、形式制約外のコマは書き出し時に近い色へ丸められます
* うごメモモードで制約を保ったコマは再減色せず書き出されます
* PPMでは編集レイヤーが形式上の2レイヤーへ集約されます
* ノーマルで追加したD〜Hはうごメモ系モードでは編集対象から外れますが、ノーマルへ戻すまで保持されます
* ノーマル作品は9,999コマまで保存できますが、PPM/KWZへ出す場合は形式上の999コマ上限をホールド展開後の枚数で判定します
* 大規模GIFは負荷を抑えるため、自動的に縮小される場合があります
* WebM書き出しは実時間録画のため、作品の再生時間ぶん待つ必要があります
* ブラウザのサイトデータを削除すると、自動保存や保存スロットも消える場合があります
* 重要作品は定期的に`.ugn2`へ保存してください
* 本プロジェクトは非公式であり、任天堂および関連各社とは関係ありません

## よくある質問

### サーバーへ作品が送られますか？

通常の描画・変換・保存はブラウザ内で行われます。専用サーバーへの作品アップロードは不要です。

### PhotoshopやAfter Effectsの代わりになりますか？

目的は、ブラウザで手軽にパラパラまんがを制作することです。高度な映像合成や3D編集は対象外です。

### 作品が重くなりました

キャンバス解像度、フレーム数、音声、高倍率書き出しを減らしてください。特にHDで多数のコマを扱う場合は端末メモリを大きく消費します。

### 自動保存があるならファイル保存は不要ですか？

不要ではありません。ブラウザのデータは、キャッシュ削除、設定初期化、端末故障などで失われる可能性があります。

### PPM/KWZを開けますか？

読み込みと書き出しに対応しています。ただし、破損状態、作成元、読み込み先の仕様によって結果が異なる場合があります。

### 写真から3DS・DSi風の多階調な作品を作れますか？

メニューの「画像からうごメモ」を使用してください。16コマを選ぶと、複数コマの異なるドット配置を30fpsで循環させ、PPMまたはKWZの少ない色を時間方向にも混ぜて階調を補います。通常の「写真」は画像を編集素材として置くだけなので用途が異なります。

### コマを増やさず線をウネウネさせられますか？

ノーマルモードで「うごきアシスト」を開き、手描きゆらぎを有効にして「設定だけで動かす」を選びます。保存画素とフレーム数は変えず、再生と書き出しのときだけ揺らぎを合成します。後から通常のコマへ変換することもできます。うごメモ・うごメモ3Dモードでは、形式との食い違いを避けるため必ず実コマへ変換します。

### うごきアシストは画像を外部AIへ送りますか？

送りません。絵の範囲、重心、輪郭、前後コマの位置差をブラウザ内の軽量な処理で調べます。ネットワーク接続や追加モデルの取得を必要としません。

### なぜ「うごくノート2」なのですか？

初代版の構造を全面的に見直して作り直した後継版であるためです。
