# ugonote2

**あの頃のうごメモも、現代のアニメーションも、すべてブラウザの上で。**

`うごくノート２` は、ブラウザだけで完結するパラパラマンガ・アニメーション制作ツールです。
ゼロから自由に描ける現代的な制作環境でありながら、ニンテンドーDSiの「うごくメモ帳（`.ppm`）」やニンテンドー3DSの「うごくメモ帳 3D（`.kwz`）」で作られた作品をそのまま読み込み、実機とまったく同じ感覚・同じ制約・同じドットアルゴリズムで編集して、再び実機形式で書き出すことができます。

SDカードの奥底で眠っている黒歴史や名作を掘り起こして加筆するもよし、最新のブラシとエフェクトで新作を描くもよし。専用ソフトのインストールも、重いプラグインも必要ありません。

---

## About / 概要

`ugonote2` は、うごメモ（`.ppm` / `.kwz`）の直接読み込み・実機同等の編集・再書き出しに対応した、ブラウザ完結型のアニメーション制作スタジオです。DSi実機（ARM9）のペン描画アルゴリズムや16bit LFSR擬似乱数、タイル圧縮、IMA-ADPCM音声処理を純粋なTypeScriptで忠実に再現。さらに現代的な13種の表現ブラシ、アニメーションエフェクト（線ゆれ・カメラモーション）、WebCodecsを用いたMP4高速出力などを備え、スマートフォンからPCまであらゆる環境で軽快に動作します。

`ugonote2` is a self-contained, browser-based flipbook animation studio with full round-trip support for Flipnote Studio (`.ppm`) and Flipnote Studio 3D (`.kwz`) files. You can open legacy Flipnotes, edit them with hardware-accurate tools, layers, and palettes, and export them back to native formats. Under the hood, it faithfully reproduces the original DSi ARM9 integer drawing algorithms, 16-bit LFSR RNG for spray/scatter brushes, binary codecs, and IMA-ADPCM audio in pure TypeScript without relying on WebAssembly. Alongside its retro hardware modes, it offers a modern animation workflow featuring 13 expressive brushes, procedural motion effects, and hardware-accelerated MP4/GIF exports.

## このツールの特徴

### 1. うごメモ（PPM / KWZ）を見るだけでなく実機通りに編集できる
単なるビューアや動画コンバータではありません。過去の `.ppm`（DSi）や `.kwz`（3DS）ファイルを読み込むと、レイヤー構造、用紙色、フレームごとのSEフラグ、BGM、さらには制作者IDやファイル名の引き継ぎ履歴（メタデータ）までそのまま展開されます。
そして最大のポイントは、当時の実機とまったく同じルールで続きが描けることです。

* **DSiモード（256 x 192 / 2レイヤー）:** 白・黒・赤・青の潔いパレットと、A/Bの2レイヤー構成。
* **3Dモード（310 x 230 / 3レイヤー）:** 6色パレットとA/B/Cの3レイヤー構成（奥行き情報も保持）。
* **ノーマルモード（自由解像度 / 3レイヤー + 写真レイヤー）:** 実機の制約から解き放たれ、フルカラー・透過・アンチエイリアスブラシが使える現代モード。

### 2. DSi実機の描画アルゴリズムをピクセル単位で再現！
実機モードのペンは、なんとなくドットっぽく見えるブラシではありません。DSi版で動いていた整数ブレゼンハム直線アルゴリズム、240Hzタッチサンプリング時の急激な座標ジャンプを抑える手ブレ補正ロジック、さらにはスプレーや拡散ペンに使われる擬似乱数までそのまま移植しています。
当時の網掛けトーンやインバート描画、アウトラインペン、速さで太さが変わるペンも、あの頃の挙動そのままに打ててしまうんです！

### 3. 現代の武器も完備（ノーマルモード & エフェクト）
懐かしいだけではありません。現代のイラスト・アニメ制作に便利な機能も詰め込んでいます。
* **13種類の表現ブラシ:** `perfect-freehand` をベースにした滑らかなペン、マーカー、鉛筆、水彩、クレヨン、エアブラシ、カリグラフィー、ネオン、チョーク、スパッタリング、リボンなど。もちろん上下・左右の対称定規も搭載。
* **アニメーションFX:** 1枚絵を描くだけでパラパラマンガ特有の「線ゆれ（Wiggle）」を自動生成したり、「呼吸」「揺れ」「浮遊」「バウンス」「カメラ手ブレ」といったモーションを付与できます。
* **フィルターエフェクト:** ぼかし、モザイク、発光、色収差、ノイズ、フチどり、波紋をレイヤーや選択範囲に適用可能。
* **ドット文字＆メモ帳フォント:** ドット絵に馴染むピクセルフォントや、縦書き・フチどり対応のテキストツールを搭載。

### 4. 音声トラックと実機ADPCMコーデック
* **BGM 1系統 + 効果音（SE）4系統:** マイクからの直接録音、音声ファイルの読み込み、フレームごとのSEトリガー配置に対応。
* **倍速・ピッチ連動:** うごメモ伝統の再生速度を変えるとBGMの速度とピッチも一緒に変わる仕様もしっかり再現。
* **IMA-ADPCMエンコード:** PPM/KWZ書き出し時には、実機仕様のサンプリングレート（8180Hz / 16364Hz）およびADPCM形式へ自動変換します。

## 対応フォーマット（入出力）

### 読み込み（Import）
| 形式 | 説明 |
| :--- | :--- |
| `.ugn2` | ugonote2 独自プロジェクト形式（全レイヤー・設定・音声を完全保存） |
| `.ppm` | うごくメモ帳（DSi）ファイル。レイヤー・音声・メタデータを維持して編集可能 |
| `.kwz` | うごくメモ帳 3D（3DS）ファイル。3レイヤー・奥行き・音声を維持して編集可能 |
| `.mp4` | 動画をパラパラ漫画として編集することが可能 |
| 画像 / PNG ZIP | 下絵や写真レイヤーへの画像配置、連番PNG（ZIP）の一括フレーム読み込み |
| 音声ファイル | BGMやSEスロットへのオーディオ読み込み（WAV / MP3 / OGG 等） |

### 書き出し（Export）
| 形式 | 説明 |
| :--- | :--- |
| `.ugn2` | 編集中の状態を丸ごとバックアップできるプロジェクトファイル |
| `.ppm` | DSi実機互換ファイル（1MB容量制限・フレームデータ上限チェック機能付き） |
| `.kwz` | 3DS実機互換ファイル（KFH / KMC / KMI / KSN チャンク生成） |
| `MP4` | `WebCodecs` + `mediabunny` による高速なH.264動画出力（音声ミックス付き） |
| `WebM` | ブラウザ標準の `MediaRecorder` を用いた動画出力 |
| `GIF` | ループアニメやSNS投稿に便利なアニメーションGIF |
| `PNG` / `PNG ZIP` | 現在フレームの静止画保存、または全フレームの連番PNG一括ZIP出力 |

> **PPM / KWZ の電子署名について:**
> 実機フォーマットの末尾には SHA-1 ハッシュおよび RSA-1024 (PKCS#1 v1.5) 署名領域が存在します。ローカルに秘密鍵（`src/codec/sigkey.local.ts`）が存在しない環境では `0xff` 等でパディング出力されますが、本ツールおよび一般的な互換ツールでの再読み込み・編集には一切支障ありません。

## 動作環境とオフライン対応（PWA）

* **すべてブラウザ内で処理:** サーバーへのデータ送信は一切ありません。自動保存や作品ライブラリはブラウザ内の `IndexedDB` に安全に記録されます。
* **Web Worker による非同期処理:** 最大 9,999 フレームの編集や重いエンコード処理、Undo/Redo用のRLE（ランレングス圧縮）差分管理も、メインスレッドを止めずにサクサク動きます。
* **PWA対応:** スマホやタブレットの「ホーム画面に追加」からインストールすれば、電波のない場所でもオフラインのネイティブアプリのように使えます。
* **単一HTMLビルド対応:** 全スクリプト・CSS・フォント・Workerをたった1つの `.html` ファイルに封入するビルドモードを備えています。サーバーすら不要で、USBメモリに入れて持ち運ぶことすら可能です。

## 開発・ビルド方法

外部フレームワーク（ReactやVueなど）やWebAssemblyには依存せず、純粋な TypeScriptとCanvas API / Web Audio API / WebCodecs APIで構築されています。バンドラには高速な `esbuild` を使用しています。

### 必要環境
* Node.js (v18以上推奨)
* npm

### セットアップとビルド

```bash
# 依存パッケージのインストール
npm install

# 開発ビルド（dist/app.js, dist/worker.js, style.css を生成）
npm run build

# ローカルサーバーで動作確認（例: Pythonを使う場合）
python -m http.server 8080
# ブラウザで http://localhost:8080/ を開く

```

### npm スクリプト一覧

| コマンド | 内容 |
| --- | --- |
| `npm run build` | 通常ビルド（バンドルのみ） |
| `npm run build:min` | 本番用ミニファイビルド |
| `npm run watch` | ファイル変更を監視して自動再ビルド |
| `npm run typecheck` | TypeScript の型チェックを実行 |
| `npm run check` | 型チェックとミニファイビルドを連続実行 |
| `npm run build:site` | ホスティング・PWA配信用のファイルを `dist/` に一式出力 |
| `npm run build:single` | 全アセット・フォント・Workerを1ファイルに統合した `dist/ugonote.html` を生成 |

```text

│   ├── codec/            # PPM / KWZ バイナリデコーダ・エンコーダ・ADPCM音声処理

├── build.mjs             # esbuild ビルドスクリプト
```
